# LexaCase - trafego pago

Landing page estatica da LexaCase para campanhas de trafego pago, com foco em conversao pelo WhatsApp e visita ao Americana Shopping.

## Estrutura

- `index.html`: conteudo da landing page.
- `styles.css`: identidade visual, responsivo e componentes.
- `script.js`: menu mobile e animacoes de entrada.
- `assets/`: imagens e videos otimizados usados no site.

## Como abrir

Abra `index.html` no navegador ou sirva a pasta com um servidor estatico.

```bash
npx serve .
```
